BubblePop v28 — Roadmap overlay integrated

Wat is geïntegreerd:
- assets/roadmap_overlay/ met de v12 roadmap-module
- nieuwe 3D bubble nodes met transparante achtergrond
- configs voor alle werelden
- dev mode via ?debug=1&dev=1 of via de roadmap zelf met Shift+D
- waypoint editing en JSON export blijven beschikbaar

Nieuwe flow:
- klik één keer op een wereld: selecteren
- klik dezelfde wereld opnieuw: roadmap openen
- klik één keer op een node: selecteren
- klik dezelfde node opnieuw: level/wereld starten

Audio:
- audio/mp3-bestanden zijn bewust niet opgenomen in deze zip.
